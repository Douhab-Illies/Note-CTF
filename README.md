# Notes CTF – Cybersécurité

## Présentation

Dans le cadre de mon apprentissage en cybersécurité, j'ai créé ce dépôt GitHub pour regrouper mes notes et les commandes que j'utilise lors des CTF (Capture The Flag).

Ce dépôt contient :
- Des méthodes pour scanner et analyser une machine.
- Des notes sur la recherche et l'exploitation de vulnérabilités.
- Des techniques d'élévation de privilèges.
- Des explications et commandes pour différents outils de pentest.

## Outils utilisés
- Nmap
- Gobuster / FFUF
- Metasploit
- LinPEAS
- Searchsploit
- Kali Linux

## Objectif

Ce dépôt me permet de garder une trace de ce que j'apprends pendant les CTF, de retrouver rapidement les commandes utiles et d'améliorer progressivement mes compétences en pentest.

**Toutes les techniques présentées sont destinées à des environnements de test autorisés.**
